PUT YOUR PHOTOS HERE
====================

Name them exactly like this:

    us-1.jpg
    us-2.jpg
    us-3.jpg
    us-4.jpg
    us-5.jpg
    us-6.jpg

Tips
----
- Portrait photos (4:5) look best, but any shape gets cropped nicely.
- Around 1200 x 1500 px is plenty. Keep each file under ~1 MB.
- If your photo is a PNG, HEIC, or WebP, convert/rename it to .jpg.
  (On Windows: open the photo in Paint -> Save as -> JPEG picture.)
- The page automatically shows a placeholder until a file is found,
  so you can add them one at a time.

Want more than 6 photos?
------------------------
Open index.html, copy one <figure class="polaroid"> block, change
data-photo="7" (and so on), then add us-7.jpg here. The grid will
fit it automatically.
